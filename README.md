# Orange-Color-Classification-Using-Machine-Learning


## Overview
This academic project focuses on classifying oranges into different color categories using machine learning algorithms in Orange Data Mining. The project compares multiple classification models and evaluates their performance.

## Dataset
- **Source:** Kaggle
- **Number of Instances:** 164
- **Features:** Size, Weight, Brix, and other dataset attributes
- **Target Classes:** Deep Orange, Light Orange, Orange, Orange-Red, Yellow-Orange

## Algorithms
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Neural Network

## Tools Used
- Orange Data Mining

## Methodology
1. Imported and explored the dataset.
2. Selected relevant features and the target variable.
3. Visualized data using Scatter Plot.
4. Applied KNN, SVM, and Neural Network models.
5. Evaluated model performance using Test & Score and Confusion Matrix.

## Results
SVM achieved the best performance among the evaluated models in this project.

Academic Project — Introduction to Artificial Intelligence and Machine Learning
